# Словарь данных

## 1. Назначение

Документ описывает основные атрибуты наборов данных, их физический смысл и аналитическую роль в исследовании.

Атрибуты разделяются на:

- характеристики игры;
- показатели интереса аудитории;
- временные характеристики;
- идентификаторы и атрибуты интеграции.

## 9. Общие атрибуты для интеграции

| Источники                     | Возможный общий атрибут                           | Надёжность       |
| ----------------------------- | ------------------------------------------------- | ---------------- |
| Steam — Steam Monthly Players | `appid` / `steam_appid`                           | Высокая          |
| Steam — RAWG                  | Нормализованное название, дата выхода             | Средняя / низкая |
| Steam — Epic                  | Нормализованное название, дата выхода             | Средняя / низкая |
| Steam — Twitch                | Нормализованное название игры                     | Средняя / низкая |
| Steam — YouTube               | Название игры, использованное в поисковом запросе | Средняя / низкая |

Совпадение названий не гарантирует идентичность игры. Для интеграции между платформами требуется нормализация названий и дополнительная проверка неоднозначных совпадений.

## 10. Принципы обработки пропусков

- Отсутствующие рейтинги не заменяются нулём.
- Отсутствующие даты не восстанавливаются без подтверждённого источника.
- Неизвестные категории сохраняются как пропуски или отдельная категория только при обоснованной необходимости.
- Пропуски в статистике YouTube не интерпретируются как отсутствие просмотров.
- При расчёте производных показателей учитывается количество доступных наблюдений.
