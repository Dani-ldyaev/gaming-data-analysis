# Реестр источников данных

## 1. Назначение

В данном документе приведён перечень источников, используемых для исследования взаимосвязи характеристик видеоигр и показателей интереса игровой аудитории.

Источники сгруппированы по типу данных и аналитическому назначению.

Статус источника:

- **Используется** — данные присутствуют локально и доступны для обработки.
- **Используется частично** — источник присутствует, но отдельные показатели или наборы требуют проверки.
- **Планируется** — источник выбран, но сбор или интеграция ещё не завершены.
- **Отложен** — подключение временно не выполняется.

## 2. Реляционные и табличные наборы данных

| Steam Dataset 2025             | `raw/steam/games_2025/`             | Игры и связанные справочники категорий, жанров, платформ, разработчиков и издателей | Используется частично  |

| Steam Reviews                  | `raw/steam/reviews/`                | Пользовательские отзывы                                                             | Используется частично  |

Основные аналитические характеристики Steam:

- числовые: `recommendations`, `positive`, `negative`, `price`, `peak_ccu`, `average_playtime_forever`, `average_playtime_2weeks`, `metacritic_score`;
- категориальные: `genres`, `categories`, `tags`, `developers`, `publishers`, `windows`, `mac`, `linux`;
- временные: `release_date`, `month`.

Ключевой идентификатор Steam — `appid`.

### 2.2. RAWG

| Набор данных       | Путь        | Содержание                                                 | Статус       |
| ------------------ | ----------- | ---------------------------------------------------------- | ------------ |
| RAWG Games Dataset | `raw/rawg/` | Каталог игр, жанры, платформы, рейтинги, теги, даты выхода | Используется |

В проекте представлены CSV, Parquet и JSONL-представления одного набора данных. Разные форматы одного источника не рассматриваются как независимые наборы данных.

Основные характеристики:

- числовые: `rating`, `ratings_count`, `reviews_count`, `metacritic`, `playtime`, `suggestions_count`;
- категориальные: `genres`, `platforms`, `stores`, `developers`, `publishers`, `esrb_rating`;
- временные: `released`, `updated`.

Идентификатор RAWG — `id`. Сопоставление с другими платформами выполняется отдельно, поскольку идентификаторы разных платформ не являются взаимозаменяемыми.

## 3. Источники с API и JSON

### 3.1. YouTube Data API v3

Документация: https://developers.google.com/youtube/data/reference/rest/v3/search/list?hl=ru

API используется для получения:

- идентификаторов видеороликов;
- названий и описаний;
- дат публикации;
- названий каналов;
- количества просмотров;
- количества отметок «Нравится» (если доступно);
- количества комментариев (если доступно).

В качестве объектов поиска используются 30 наиболее популярных игр Steam, отобранных по полю `recommendations`.

Ограничения:

- поисковая выдача не гарантирует, что каждый ролик относится непосредственно к игре;
- название игры может совпадать с другими сущностями;
- статистика видео отражает накопленные значения на дату сбора;
- API key хранится локально в `.env`.

Статус: планируется / реализуется в рамках этапа 2.2.

## 4. Неструктурированные данные

### 4.1. Habr

Используются публикации, посвящённые игровой индустрии, платформе Steam и распределению внимания аудитории.

Материалы:

1. https://habr.com/ru/articles/995396/
2. https://habr.com/ru/articles/1072012/

Извлекаемые данные:

- заголовок;
- дата публикации;
- автор (если доступен);
- текст публикации;
- URL;
- тематические ключевые слова.

Тексты используются для демонстрации обработки неструктурированных данных: очистки, токенизации и TF-IDF-векторизации.

Две статьи не являются репрезентативной выборкой всей игровой индустрии. Их анализ рассматривается как демонстрация технологического этапа обработки текстовых данных и контекстный материал.

Статус: планируется / реализуется.

## 5. Источник XML

### 5.1. Росстат

Росстат рассматривается как потенциальный источник официальных статистических данных в XML или ином машиночитаемом формате.

Планируемый период — 2023–2025 годы.

Подключение временно отложено из-за недоступности источника на момент подготовки проекта. Файлы и их структура должны быть получены и проверены отдельно.

До проверки файлов требование пункта 3.2 методички не считается выполненным.

Статус: отложен.

## 6. Исключённые и неиспользуемые источники

В текущей реализации не используются:

- Steam API;
- RAWG API;
- набор Steam Player Data 2012–2021, ранее исключённый из отбора;
- дополнительные источники, которые не прошли проверку доступности, качества или соответствия предмету исследования.

## 7. Соответствие требованиям методички

| Требование                          | Источник                  | Статус                       |
| ----------------------------------- | ------------------------- | ---------------------------- |
| Не менее одного реляционного набора | Steam, RAWG, Epic, Twitch | Выполняется                  |
| Не менее одного XML-набора          | Росстат                   | Не выполнено, ожидается файл |
| Не менее одного API с JSON          | YouTube Data API v3       | В процессе реализации        |
| Неструктурированные данные          | Статьи Habr               | В процессе реализации        |

Для каждого набора данных отдельно проверяется наличие не менее трёх категориальных и трёх числовых характеристик. Если источник не содержит требуемых характеристик или они имеют слишком большое число пропусков, это фиксируется как ограничение, а не компенсируется искусственным созданием показателей.
